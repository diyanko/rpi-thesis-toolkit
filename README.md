# RPI Thesis Toolkit

An unofficial, community-made starter for Rensselaer Polytechnic Institute
(RPI) graduate students.

**A LaTeX starter and plain-language guide for RPI theses and dissertations, written for first-time LaTeX users too.**

Get the starter, compile your first PDF, and let one shared formatting file
(`rpi-thesis.cls`) handle margins, page numbers, headings, contents, and
references, on your own computer, on Overleaf, or both. Draft wherever you
and your advisor work best, and bring each chapter in when it is ready. No programming, Git, or
paid software required.

Writing an undergraduate thesis, a course paper, slides, or a poster? The
writing, citation, and figure help works for you too. The title page and page
layout follow RPI's graduate rules, so check your own program's requirements.

**[Read the guide on the website](https://diyanko.github.io/rpi-thesis-toolkit/)**
(or [in this repository](docs/get-started.md))

> [!IMPORTANT]
> The official requirements are on OGE's
> [thesis and dissertation submission page](https://graduate.rpi.edu/academic-progress/submit-your-thesis-dissertation),
> and RPI's official LaTeX template and the RPI seal are on RPI ITS's
> [Thesis Preparation page](https://itssc.rpi.edu/hc/en-us/articles/360010087512-Thesis-Preparation).
> This toolkit works alongside them; always check your document against
> OGE's current requirements.

## Privacy

The website uses [Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/about/)
for aggregate page views, visits, referrers, and page performance. Cloudflare
describes its [privacy protections](https://www.cloudflare.com/web-analytics/):
no cookies, local storage, or fingerprinting to track visitors. The site adds no Google Analytics, advertising tags, or visitor IDs.
Search Console measures the site's appearance in Google Search; its ownership
verification tag adds no visitor-tracking script.

An optional counter records the first download or Open in Overleaf click in
one browser tab session. It sends only a fixed download type to Cloudflare;
the database stores a daily total for each type. A temporary yes/no flag in
your tab prevents repeated clicks from being counted again. No visitor ID,
IP address, referrer, page address, or raw click record is stored by the counter.
Cloudflare still handles network requests under its
[privacy policy](https://www.cloudflare.com/privacypolicy/).
These counts estimate download sessions, not people, successful installations,
or actual thesis use. Direct GitHub downloads and automated file checks do
not use this counter. Browser automation and local previews are excluded;
some bots and repeat visits can still affect totals.

The browser choice applies to both page analytics and download counts. It
stays on this device; repeat it in each browser or after clearing browser data.
Reload other open tabs to apply a changed choice to their page analytics.
Global Privacy Control and Do Not Track also turn measurement off. With
JavaScript disabled, neither measurement script runs. Downloads always work
without measurement.

Guide search and the browser tools process your text and files on your device;
they do not send that content to analytics or upload it. The offline guide in
the ZIP includes no analytics. Your appearance preference is saved in your
browser so it works on your next visit.

GitHub hosts the site and release downloads under its
[privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
GitHub provides aggregate release download counts; these count requests,
including automated checks and repeat downloads, rather than individual people.
Following a link to another service uses that service's privacy practices.
For a privacy question, use [the help and feedback form](docs/troubleshooting.md#ask-for-help).
